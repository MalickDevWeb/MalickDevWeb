### ⬡ Hexagonal

```text
                 External Systems
                        │
                    Adapters
                        │
                        ▼
                  ┌───────────┐
                  │   Ports   │
                  └─────┬─────┘
                        │
                        ▼
                  ┌───────────┐
                  │   DOMAIN  │
                  └───────────┘
```

### ⚡ CQRS

```text
                    APPLICATION
                         │
                ┌────────┴────────┐
                │                 │
             COMMAND             QUERY
                │                 │
                ▼                 ▼
             WRITE              READ
                │                 │
                ▼                 ▼
            WRITE DB            READ DB
```

Lorsque nécessaire, les modèles de lecture et d'écriture peuvent être séparés afin d'optimiser indépendamment les workloads.
